OKS Library

  • Fix bug with wrong objects list returned by referenced_by() method from config package. The patch fixes calculation of RCRs by OksObject::SetRelationshipValue(const OksDataInfo * odi, OksData * d) method (see bug 82615).
  • Fix problem when OKS file was created incorrectly by third-party tools: if creation date tag in the info section is missing (see bug 70563), after saving by OKS on reload it resulted "not-a-date-time" error.
  • Fix several internal problems connected with execution of OKS code in several threads and several OKS kernels discovered during RDB writer server exploitation:
    • bug 76158: the server may go into error state when several clients are updating OKS server repository;
    • bug 78326: the server may crash, when several clients actively update database caused by fast boost allocator with null mutex;
    • bug 82762: the server may crash under certain conditions during database reload.
